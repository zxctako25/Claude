# Claude API Chat Application

Минималистичное приложение для обмена сообщениями с ИИ-моделью Claude и другими моделями с использованием вашего личного API-ключа.
> [!IMPORTANT]
> Приложение разработано исключительно для Windows, так же, приложение было разработано специально под иной сервис который предоставляет API-ключи, https://app.claudehub.fun/ В будущем приложение будет предоставлять и другие возможности подключить другой сервис и его API-ключ!

---

## Особенности

* Прямое подключение по API: Полный контроль над вашим ключом и запросами без посредников.
* Интерактивный чат: Удобный интерфейс для ведения диалога с нейросетью.
* Быстрый отклик: Оптимизированное взаимодействие с API.
* Безопасность: API-ключи хранятся только локально на вашем устройстве.

---

## Быстрый старт

### Предварительные требования

1. Установленный Qt6 Creator + Его зависимости.
2. Активный API-ключ Anthropic (получить можно в (https://app.claudehub.fun/).

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/zxc_tako25/claude.git
   cd название-репозитория
   ```

2. Настройте окружение:
   Откройте приложение `Qt6 Create` установив все зависимости и импортировав проект:
   ```source code
   зайдите в файл mainwindow.h - и вставьте свой API-ключ QString apiKey  = "sk-hub-";
   ```

3. Запустите приложение:
   ```CMake
   собирите приложение с помощью инструментов Qt6 и запустите Claude.exe в папке ~/Claude/build/папка которая создалась/Claude.exe
   ```
